# deck

La charla «Descubriendo Flutter» hecha en Flutter Web. Ver `../PREPARACION.md`.

- `fvm flutter run -d chrome`: ensayar con hot reload.
- `fvm flutter build web --release --no-web-resources-cdn`: el build para presentar.
- `fvm flutter test`: tests; `fvm flutter test tool/capturas_test.dart`: un PNG por diapositiva en `build/capturas/`.
